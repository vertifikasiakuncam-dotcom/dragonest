# Prebuilt Linux Server

Folder ini menyimpan binary server Dragon Nest Mobile untuk Linux. File binary akan diunggah manual setelah pemeriksaan versi, arsitektur, dependensi, dan keamanan.

**Peringatan:** Jangan jalankan binary yang belum diverifikasi. Keenam komponen di bawah harus berasal dari paket/versi yang sama.
